免费、安全、无广告

htmlGenius 不提供或托管模型。它只把你明确选中的修改契约交给你电脑上已经登录的 Agent，并让 Agent 写出一份可审查的候选 HTML。

从安装到连接，一步一步来。

不熟悉 Terminal 也没关系。配置文档会带你检查环境、连接 Bridge，并确认本机 Agent 已就绪。

从评论到候选版

每次执行都有清晰边界。

1

你选择输入

只有当前选择的评论和你填写的目标、保护项会进入任务；未选内容留在评论收件箱。

2

Agent 只写候选

原文件不会自动覆盖。完成后以 V1.1、V1.2…的独立文件返回，便于比较和回退。

3

你决定是否采用

候选自动打开，已有评论尽可能重新定位。继续评论、再生成或放弃，都由你决定。
