核心摘要本机 Agent评论与协作控制与删除权限说明
核心摘要

只收集功能需要的数据。

htmlGenius 是 Chrome 扩展。它让你在网页上评论和编辑；如果你登录并使用协作功能，相关评论会保存到 htmlGenius 自有后端用于同步。我们不接入广告网络，也不使用第三方行为分析。

关键区别：协作评论同步到 htmlGenius 后端；本机 Agent 生成路径则只在你的电脑与已登录的 Agent 之间发生。两条数据路径不能混为一谈。
LOCAL AGENT FLOW

你主动发起时，内容只交给你的本机 Agent。

当你点击“发送给 Codex / Claude Code”时，选中的评论、相关页面内容和修改契约经浏览器 Native Messaging 发送给你电脑上已安装并登录的 Agent。htmlGenius 不会将这部分页面内容、评论或 Agent 凭证上传给作者或任何服务端。

  • 不读取、不保存 API Key、Token、Cookie 或 Agent 登录态。
  • 不列举、读取、接管或注入你已经在运行的外部 Agent 会话。
  • Agent 只生成独立候选版本，不自动覆盖你的原 HTML。
评论与协作

协作数据服务于同步，而不是广告或训练。

如果你选择登录并使用协作评论，系统会处理账号基础身份信息和评论内容，以便显示作者、保存、同步和执行作者权限控制。我们不出售个人信息，不接入广告网络。

  • Google 登录只使用 openid、email、profile 等基础范围。
  • 飞书登录仅在你主动点击时调用，用于识别账号与显示昵称。
  • 你可以编辑或删除自己创建的评论；作者身份用于保护这项权限。
控制与删除

你控制自己的内容。

你可以在侧边栏删除自己创建的评论，退出登录使当前会话失效，并通过正式隐私政策列出的联系方式请求删除账号及相关数据。正式版会保留具体的请求入口、处理说明与生效日期。

权限说明

每一项 Chrome 权限都对应一个明确功能。

  • activeTab / sidePanel / host permissions：在当前网页显示评论与编辑界面。
  • storage：保存本机偏好、会话和本地评论状态。
  • identity：完成 Google / 飞书登录。
  • nativeMessaging：仅在你主动使用本机 Agent 时，与本机 bridge 通信。
  • notifications / offscreen：候选版本完成时显示本机通知和提示音。
