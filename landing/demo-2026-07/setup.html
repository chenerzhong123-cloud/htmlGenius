连接本机 Agent
一键生成新版文件

完成后，你选择的评论可以交给本机已登录的 Codex、Claude Code 或 Copilot，生成独立候选 HTML；原文件不会被覆盖。

适用范围：仅支持 macOS、Chrome 116+ 与 Node.js 20.x 或 22+。至少准备一个已登录的 Agent；使用 Copilot 时需要 Node.js 20.19+ 或 22.12+。Windows / Linux 仍可复制 Prompt 手动交给 Agent。
推荐顺序

三步完成连接。

推荐亲自在 Terminal 中运行固定版本的命令。扩展会为你准备好扩展 ID，复制后直接粘贴即可。

  1. 1

    确认电脑已准备好

    打开 Terminal，输入 node -v。看到 20.x 或 22+ 即可；然后确认 Chrome 已安装，并至少登录了一个你要使用的 Agent。

    Terminal
    ❯ node -v
    v22.12.0
    macOSChrome 116+Node.js 20.x / 22+
  2. 2

    安装 Bridge

    推荐

    在 Side Panel 打开“整理评论，创建编辑任务”。Connection Center 中点击“复制 Terminal 命令”，再粘贴到 Terminal 运行。这个命令已自动带上当前电脑的扩展 ID。

    htmlGeniusConnection Center
    尚未连接本地 Agent
    扩展 ID 已自动填入
    这是用户级安装：Bridge 只在本机注册 Chrome 连接组件，不会安装或登录任何 Agent，也不需要管理员权限。

    如果没有看到复制按钮：在 chrome://extensions 找到 htmlGenius 的 32 位扩展 ID，替换下面的占位符。先跑只读检查，再执行安装。

    只读检查，不写入文件
    npx --yes @htmlgenius/bridge@1.0.6 doctor --json --extension-id <你的扩展ID>
    确认后安装
    npx --yes @htmlgenius/bridge@1.0.6 setup --json --scope user --extension-id <你的扩展ID>
  3. 3

    登录 Agent，然后检查连接

    Codex：安装并登录官方 Codex / ChatGPT Mac App。Claude Code：在 Terminal 完成 claude auth login。Copilot：登录本机 Copilot。回到 Connection Center 点击“检查连接”。

    Connection Center检查完成
    ✓Codex已连接
    ✓Claude Code已连接
    ✓ 官方 App / CLI 已登录✓ Agent 显示绿点
备用方式

也可以让 Agent 帮你执行。

Connection Center 的“让 Agent 帮我连接”会复制一段固定的 Setup Prompt，只含扩展 ID 与 Bridge 版本。它会按 doctor → setup → doctor 的顺序操作。

这会调用终端命令，部分 Agent 会提示风险，这是正常的安全保护。Bridge 为 MIT 开源项目；运行前你可以把命令和开源仓库交给自己的 Agent 审阅，再决定是否继续。

连接后怎么用

只支持把本地 HTML 直接发送给 Agent。

打开 file:///… 的本地 HTML，添加至少一条评论，在“整理评论，创建编辑任务”中选择评论和修改范围，再从发送菜单选择已连接的 Agent。远程网页（http / https）不能直接发送，但始终可以复制 Prompt 手动交给任意 AI。

遇到问题？

先检查这四项。

仍显示“尚未连接”确认 setup 使用的是当前扩展 ID；然后在 chrome://extensions 刷新 htmlGenius，再点“检查连接”。
找不到 Claude Code 或 Copilot先确认已安装并登录；Bridge 只会在常见的用户级目录与 node 所在目录寻找 CLI。
Copilot 显示不兼容运行 node -v。Copilot 需要 Node.js 20.19+ 或 22.12+；不满足时可先用 Codex 或 Claude Code。
需要进一步排查在 Connection Center 使用“复制诊断”。诊断为脱敏 health JSON，不包含路径、Token 或历史会话。
需要移除？

卸载只会删除 Bridge 自己的文件。

npx --yes @htmlgenius/bridge@1.0.6 uninstall --json --scope user
